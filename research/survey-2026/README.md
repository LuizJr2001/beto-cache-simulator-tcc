# Levantamento de requisitos com usuários

Este diretório reúne os dados publicáveis do formulário **Levantamento de Requisitos para Aprimoramento do Simulador Beto**, aplicado no contexto do TCC entre 29 de maio e 12 de junho de 2026.

## Arquivos

- `resumo-agregado-respostas.pdf`: gráficos e respostas abertas apresentados pelo resumo do Google Forms;
- `respostas-anonimizadas.csv`: 13 respostas individuais, identificadas apenas pelos códigos `R01` a `R13`.

## Tratamento dos dados

O formulário autorizou o uso anonimizado das respostas para fins acadêmicos. Por isso, os arquivos originais não foram incluídos neste repositório público. Foram removidos:

- os endereços de e-mail dos participantes;
- os carimbos individuais de data e hora;
- a página do resumo que relacionava os e-mails coletados.

As respostas às perguntas da pesquisa foram preservadas sem alterações de conteúdo. Os códigos de resposta servem apenas para diferenciar os registros e não permitem identificar os participantes.

## Finalidade

Os dados apoiam o levantamento e a priorização de requisitos, a análise de problemas de usabilidade e a definição das melhorias do simulador Beto. O uso deve permanecer restrito às finalidades acadêmicas previstas no termo de consentimento.
